Installation with Docker

Here we maintain Dockerfiles for different compilers. They reuse the Spack environments stored under utilities/spack.

Usage

🍎 Running on Apple Silicon (ARM) Macs
Our images are built for linux/amd64, but they run on M-series Macs through Docker Desktop's built-in emulation. Just add --platform linux/amd64 to your docker run command, for example:
docker run --platform linux/amd64 -it -v ${PWD}:/work --rm --privileged peanoframework/<compiler>
For users, it is recommended to pull the available Docker images from Dockerhub. All Docker images that have the extension gcc, intel, nvidia, llvm, or amd provide all commonly the same dependencies that are needed to build, run and visualise Peano applications. All dependencies within the images are installed via Spack. Each image additional provides one of the compilers with MPI that are also configured for GPU offloading. You may choose any image to pull from Dockerhub that fits your needs in a compiler and your hardware configuration.
You may ignore images that have the extension base, or spack. These are only used for development.
To use the prebuilt images, we do recommended that you first clone Peano, then navigate into the Peano checkout and run the Docker container interactively by mapping the Peano directory into the container (here, we use work as our mapping point):
docker run -it -v ${PWD}:/work --rm --privileged peanoframework/<compiler>

With GPU Support

docker run -it -v ${PWD}:/work --rm --gpus=all --privileged peanoframework/<compiler>

With Port Forwarding (JupyterLab)

docker run -it -v ${PWD}:/work -p 8888:8888 --rm --privileged peanoframework/<compiler>
and then you can run
jupyter lab --allow-root --port=8888 --no-browser --ip=0.0.0.0

Build (for Developers)

The next part is mostly relevant for developers of the project or if you want to change or add some additionally dependencies to the Docker images yourself. Keep in mind, that building the image takes a significant amount of time and requires root access.
To build the Docker images, make sure to execute the following commands in the Peano root directory.

Building Base Images

docker build -t peanoframework/base -f utilities/docker/Dockerfile.base .
docker build -t peanoframework/spack -f utilities/docker/Dockerfile.spack .

Building Compiler Images

docker build -t peanoframework/gcc -f utilities/docker/Dockerfile.gcc .
docker build -t peanoframework/intel -f utilities/docker/Dockerfile.intel .
docker build -t peanoframework/nvidia -f utilities/docker/Dockerfile.nvidia .
docker build -t peanoframework/amd -f utilities/docker/Dockerfile.amd .
docker build -t peanoframework/llvm -f utilities/docker/Dockerfile.llvm .

Building Extension Images

docker build -t peanoframework/exahype2 -f utilities/docker/Dockerfile.exahype2 .
docker build -t peanoframework/exahype2-tutorials -f utilities/docker/Dockerfile.exahype2-tutorials .
