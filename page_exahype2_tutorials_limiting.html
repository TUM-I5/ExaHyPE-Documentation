This tutorial adds the last big ingredient: a limiter. We solve a 2D Riemann (shock-tube) problem for the compressible Euler equations: a corner of low-density, low-pressure gas sits in a box of dense, high-pressure gas. When the simulation starts, the dense gas rushes into the corner, launching shock waves and contact discontinuities. The notebook is tutorials/04_limiting/EulerShock.ipynb, with its implementation in ADERDGSolver.cpp and Limiter.cpp.

Why a Limiter

A high-order ADER-DG scheme is accurate where the flow is smooth, but it overshoots and undershoots near discontinuities (Gibbs oscillations). Those oscillations can drive the density or pressure negative and crash the run. The a-posteriori limiter** keeps the scheme both accurate and robust:

  • after each time step every cell is checked against a discrete maximum principle (DMP) and a user-supplied physical admissibility criterion;
  • a cell that fails - a troubled cell - is rolled back and recomputed with a robust Finite Volumes scheme on a subgrid of 2 * order + 1 volumes;
  • everywhere else the high-order ADER-DG solution is kept.

The Equations

We solve the 2D compressible Euler equations for density \(\rho\), momentum \(\rho \mathbf{u}\) and energy \(E\). There is no source term. The conserved variables are addressed through the generated Shortcuts enum (Shortcuts::rho, Shortcuts::j + 0/1, Shortcuts::E), so the same indices work in both implementation files.

The Configuration

The domain is the box \([-1, 1]^2\). The bottom-left quadrant starts with \(\rho = 0.125,\ p = 0.1\) and the rest of the box with \(\rho = 1,\ p = 1\), both at rest. The outer state never changes during the run, so the boundaries are Dirichlet conditions that simply hold that initial outer state.

Limiting is a feature of a discontinuous Galerkin solver rather than a solver of its own. We create the high-order ADERDGSolver and switch its limiter on with add_subcell_limiter. The subcell scheme a troubled cell falls back on evaluates the same flux and eigenvalue as the high-order scheme: 

aderdg_solver = exahype2.solvers.aderdg.GlobalAdaptiveTimeStep(
    name = "ADERDGSolver", order = 5, ...
)
aderdg_solver.add_subcell_limiter(
    limiter_solver                   = exahype2.solvers.fv.godunov.subcell_scheme(),
    number_of_dmp_observables        = 4,
    dmp_relaxation_parameter         = 0.01,
    dmp_differences_scaling          = 0.03,
    dmp_observables                  = exahype2.solvers.PDETerms.User_Defined_Implementation,
    physical_admissibility_criterion = exahype2.solvers.PDETerms.User_Defined_Implementation,
)

A cell is recomputed when either test rejects its candidate. The discrete maximum principle takes the observables written in Limiter.cpp and requires the candidate to stay inside the range the cell itself held one step earlier, widened by the dmp_* parameters. The troubled-cell test rejects any state that is not finite or whose density or pressure is not positive.

The Implementation Files

ADERDGSolver.cpp holds the Euler equations as a 2D Riemann problem. The subcell scheme a troubled cell falls back on evaluates these same terms. A density floor keeps the reciprocal finite when an oscillation briefly pushes a cell towards the vacuum, and the eigenvalue takes the magnitude of the pressure, so a candidate the limiter is about to reject still yields a finite time step:

// This file is part of the ExaHyPE 2 project. For conditions of distribution and
// use, please see the copyright notice at www.peano-framework.org
//
// Worked ADER-DG implementation for the compressible Euler equations, set up as
// a 2D Riemann (shock) problem. The conserved variables are addressed through
// the generated Shortcuts enum:
// Shortcuts::rho density (1 component)
// Shortcuts::j momentum (2 components: +0 is x, +1 is y)
// Shortcuts::E total energy (1 component)
//
// The subcell scheme a troubled cell falls back on evaluates these same terms.
#include "ADERDGSolver.h"
namespace {
constexpr double Gamma = 1.4;
constexpr double ShockPosition = 0.111;
// A high-order candidate can reach the vacuum at a shock before the limiter
// rejects it. The floor lies far below any density the limiter accepts, so it
// bounds the reciprocal without altering an admissible state.
constexpr double DensityFloor = 1.0e-12;
double momentumSquared(const double* const Q) {
using Shortcuts = tutorials::exahype2::limiting::ADERDGSolver::Shortcuts;
double result = 0.0;
for (int dimension = 0; dimension < DIMENSIONS; dimension++) {
result += Q[Shortcuts::j + dimension] * Q[Shortcuts::j + dimension];
}
return result;
}
} // namespace
void tutorials::exahype2::limiting::ADERDGSolver::initialCondition(
double* const NOALIAS Q,
const tarch::la::Vector<DIMENSIONS, double>& cellCentre,
const tarch::la::Vector<DIMENSIONS, double>& cellSize
) {
// The jump between the corner and the rest of the box drives the shocks and the
// contact this tutorial limits.
const bool inLowPressureCorner = cellCentre[0] < -ShockPosition and cellCentre[1] < -ShockPosition;
const double pressure = inLowPressureCorner ? 0.1 : 1.0;
Q[Shortcuts::rho] = inLowPressureCorner ? 0.125 : 1.0;
Q[Shortcuts::j + 0] = 0.0;
Q[Shortcuts::j + 1] = 0.0;
Q[Shortcuts::E] = pressure / (Gamma - 1.0);
}
void tutorials::exahype2::limiting::ADERDGSolver::boundaryConditions(
const double* const NOALIAS Qinside,
double* const NOALIAS Qoutside,
const tarch::la::Vector<DIMENSIONS, double>& faceCentre,
const tarch::la::Vector<DIMENSIONS, double>& cellSize,
const double time,
const int normal
) {
// Hold the initial outer state at the boundary (the shocks never reach it).
const bool inLowPressureCorner = faceCentre[0] < -ShockPosition and faceCentre[1] < -ShockPosition;
const double pressure = inLowPressureCorner ? 0.1 : 1.0;
Qoutside[Shortcuts::rho] = inLowPressureCorner ? 0.125 : 1.0;
Qoutside[Shortcuts::j + 0] = 0.0;
Qoutside[Shortcuts::j + 1] = 0.0;
Qoutside[Shortcuts::E] = pressure / (Gamma - 1.0);
}
void tutorials::exahype2::limiting::ADERDGSolver::flux(
const double* const NOALIAS Q,
const tarch::la::Vector<DIMENSIONS, double>& cellCentre,
const tarch::la::Vector<DIMENSIONS, double>& cellSize,
const double time,
const double timeStepSize,
const int normal,
double* const NOALIAS F
) {
const double inverseDensity = 1.0 / std::max(Q[Shortcuts::rho], DensityFloor);
const double pressure = (Gamma - 1.0) * (Q[Shortcuts::E] - 0.5 * inverseDensity * momentumSquared(Q));
const double normalMomentum = Q[Shortcuts::j + normal];
F[Shortcuts::rho] = normalMomentum;
F[Shortcuts::j + 0] = normalMomentum * Q[Shortcuts::j + 0] * inverseDensity;
F[Shortcuts::j + 1] = normalMomentum * Q[Shortcuts::j + 1] * inverseDensity;
F[Shortcuts::E] = normalMomentum * inverseDensity * (Q[Shortcuts::E] + pressure);
F[Shortcuts::j + normal] += pressure;
}
double tutorials::exahype2::limiting::ADERDGSolver::maxEigenvalue(
const double* const NOALIAS Q,
const tarch::la::Vector<DIMENSIONS, double>& cellCentre,
const tarch::la::Vector<DIMENSIONS, double>& cellSize,
const double time,
const double timeStepSize,
const int normal
) {
const double inverseDensity = 1.0 / std::max(Q[Shortcuts::rho], DensityFloor);
const double pressure = (Gamma - 1.0) * (Q[Shortcuts::E] - 0.5 * inverseDensity * momentumSquared(Q));
// The time step is computed before the limiter has judged the cell, so a
// candidate whose pressure has gone negative still has to yield a finite bound.
const double soundSpeed = std::sqrt(std::abs(Gamma * pressure * inverseDensity));
const double normalVelocity = Q[Shortcuts::j + normal] * inverseDensity;
return std::abs(normalVelocity) + soundSpeed;
}

Limiter.cpp holds the two callbacks the limiter asks the solver for: the troubled-cell test, and the observables the discrete maximum principle bounds. The solver declares them only while the limiter is configured, so the notebook adds this file to the build only then:

// This file is part of the ExaHyPE 2 project. For conditions of distribution and
// use, please see the copyright notice at www.peano-framework.org
#include "ADERDGSolver.h"
namespace {
constexpr double Gamma = 1.4;
// The Euler equations describe a gas only while density and pressure are
// strictly positive, so a candidate that reaches either floor goes to the
// subcell scheme.
constexpr double DensityFloor = 1.0e-12;
constexpr double PressureFloor = 1.0e-12;
// Positions in the observable vector the discrete maximum principle bounds.
constexpr int Density = 0;
constexpr int Velocity = 1;
constexpr int Pressure = 1 + DIMENSIONS;
double momentumSquared(const double* const Q) {
using Shortcuts = tutorials::exahype2::limiting::ADERDGSolver::Shortcuts;
double result = 0.0;
for (int dimension = 0; dimension < DIMENSIONS; dimension++) {
result += Q[Shortcuts::j + dimension] * Q[Shortcuts::j + dimension];
}
return result;
}
} // namespace
bool tutorials::exahype2::limiting::ADERDGSolver::isPhysicallyAdmissible(
const double* const NOALIAS Q,
const int numberOfStates,
const tarch::la::Vector<DIMENSIONS, double>& cellCentre,
const tarch::la::Vector<DIMENSIONS, double>& cellSize
) const {
constexpr int NumberOfData = NumberOfUnknowns + NumberOfAuxiliaryVariables;
// Q holds numberOfStates consecutive states: every node of a candidate
// polynomial, or a single state when one finite-volume value is checked.
const double* state = Q;
for (int stateNumber = 0; stateNumber < numberOfStates; ++stateNumber, state += NumberOfData) {
for (int unknown = 0; unknown < NumberOfData; ++unknown) {
if (not std::isfinite(state[unknown])) {
return false;
}
}
const double density = state[Shortcuts::rho];
if (density <= DensityFloor) {
return false;
}
const double pressure = (Gamma - 1.0) * (state[Shortcuts::E] - 0.5 * momentumSquared(state) / density);
if (pressure <= PressureFloor) {
return false;
}
}
return true;
}
void tutorials::exahype2::limiting::ADERDGSolver::mapDmpObservables(
double* const NOALIAS observables,
const double* const NOALIAS Q
) const {
static_assert(
NumberOfDMPObservables == Pressure + 1,
"The mapping fills the density, one velocity component per axis and the pressure."
);
const double inverseDensity = 1.0 / std::max(Q[Shortcuts::rho], DensityFloor);
observables[Density] = Q[Shortcuts::rho];
for (int dimension = 0; dimension < DIMENSIONS; dimension++) {
observables[Velocity + dimension] = Q[Shortcuts::j + dimension] * inverseDensity;
}
observables[Pressure] = (Gamma - 1.0) * (Q[Shortcuts::E] - 0.5 * inverseDensity * momentumSquared(Q));
}

Running and Visualising

export OMP_NUM_THREADS=4
./EulerShock -et 2.0 -ns 20 -l 3

We plot the energy from the ADERDGSolver (use the field dropdown to switch to density, momentum or pressure): 

from postprocessing import render_solution
render_solution.show_solution("ADERDGSolver", field="E")

Drag the time slider to partway through the run, where the structure is clearest:

The energy at \(t \approx 0.8\): the curved shock front, the contact discontinuities and the central jet of the 2D Riemann problem all stand out. The limiter keeps the solution physical (positive density and pressure) right through these discontinuities, quietly swapping troubled ADER-DG cells for Finite Volume ones.

The limiter also writes a LimiterStatus field beside the solution, so picking it in the dropdown shows which cells ran on the Finite Volume subgrid at each snapshot. Expect a thin band tracking the shocks and the contact.

Why We Need the Limiter

The limiter is not a cosmetic detail here - the scheme is unusable without it. In the notebook, go back to the solver cell, set 

use_limiting = False

and re-run from there. Now only the high-order ADER-DG scheme runs, with no Finite Volume fallback, and it oscillates uncontrollably at the shock fronts. Within the first couple of percent of the run those oscillations drive the density negative, the state then grows without bound, the reported maximum eigenvalue jumps by more than an order of magnitude, and the time step collapses with it.

You do not have to interrupt anything. Once the time step underflows, ExaHyPE trips a noncritical assertion on it, dumps the final state and shuts down within seconds, and the non-zero exit status makes the run cell raise. The dumped snapshot is worth plotting: its densities and energies are many orders of magnitude away from anything physical, and both signs appear where only positive values are meaningful. That is the whole point of a-posteriori limiting: for problems with shocks, a high-order scheme on its own is not robust, and the limiter is what makes it usable.

Experiment

  • Refine the mesh with -l 4 for sharper shocks (slower).
  • Loosen or tighten the limiter via dmp_relaxation_parameter and dmp_differences_scaling, and watch how many cells get limited.
  • Move the initial discontinuity (ShockPosition in ADERDGSolver.cpp).
